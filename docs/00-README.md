# Project Documentation

This folder contains the product and engineering documents that explain why CommerceOS exists, how it is intended to work, and what has been implemented.

- `MyVision.md` — the original product vision and non-negotiable design principles.
- `IMPLEMENTATION_PLAN.md` — the architecture, standards research, target boundaries, and acceptance criteria.
- `IMPLEMENTATION_STATUS.md` — completed work and the remaining implementation risks.
- `agent_native_commerce_idea.md` — the concise early statement of the agent-native commerce idea.

These documents are reference material, not application runtime code.
